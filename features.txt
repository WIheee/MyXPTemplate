# ══════════════════════════════════════════════════════════════════
#  features.txt —— 功能清单（唯一数据源）
# ══════════════════════════════════════════════════════════════════
#
#  加功能 = 加一行 → 跑 python feature_tool.py gen
#  或者   = python feature_tool.py add   （交互式，不用记格式）
#
#  格式（用 | 分隔，两边空格可选）：
#
#    @tab  <枚举名> | <中文> | <英文> | <图标文件名>
#
#    <枚举名> | <中文> | <英文> | <中文描述> | <英文描述> | <toggle|action> | <tab枚举名小写>
#
#  规则：
#    · 以 # 开头的行是注释
#    · @tab 定义 Tab 页，图标文件放在 assets/ 下
#    · 其余行定义一个功能，最后一列指明属于哪个 tab
#    · action 只出现在 actions 区；toggle 只出现在 toggles 区
#    · 同一 tab 下多行按书写顺序排列
# ══════════════════════════════════════════════════════════════════
